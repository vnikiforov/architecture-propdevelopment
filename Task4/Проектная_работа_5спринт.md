| Роль | Права роли | Группы пользователей |
|------|-------------|---------------------|
| dba-admins-role | - Полный доступ к ресурсам БД (StatefulSets, PersistentVolumeClaims)<br>- Чтение конфигураций (ConfigMaps, Secrets)<br>- Мониторинг метрик БД | dba-admins |
| domain-admins-role | - Управление доменными ресурсами (Ingress, Services)<br>- Управление DNS записями<br>- Настройка сетевых политик | domain-admins |
| system-readers-role | - Только чтение всех ресурсов кластера<br>- Просмотр логов<br>- Доступ к метрикам мониторинга | system-readers |
| system-configurators-role | - Настройка кластерных ресурсов (Nodes, StorageClasses)<br>- Управление Namespace<br>- Настройка RBAC | system-configurators |
| cross-functional-admin-role | - Комбинированные права dba-admins и domain-admins<br>- Расшираненный доступ для кросс-функциональных администраторов | dba-admins, domain-admins |
